SOBRE O PROJETO

Tudo o que uma sessão precisa.

O CineWord é um projeto acadêmico para organizar a programação de um cinema, da escolha do filme ao controle das sessões.

01 / EXPLORAR

Encontre sua sessão

Veja a programação, filtre por filme, gênero, data ou disponibilidade e consulte os detalhes de cada exibição.

02 / ORGANIZAR

Monte a programação

Cadastre e edite filmes, classificações, salas, datas e horários no painel de administração.

03 / ACOMPANHAR

Mantenha tudo em dia

Altere a disponibilidade, exclua sessões com confirmação e acompanhe o resumo da programação.

LOCALIZAÇÃO

Encontre o cinema

Onde os dados ficam salvos?

@if (service.modoLocal) {

Esta versão usa o modo local. As sessões ficam salvas neste navegador e continuam disponíveis depois de atualizar a página. Outro navegador ou dispositivo terá seus próprios registros.

No primeiro acesso são incluídas 12 sessões fictícias para a demonstração. Limpar os dados do site remove os cadastros locais. O Firebase ainda não está conectado.

} @else {

Esta versão está configurada para usar o Firebase Realtime Database. O acesso depende da conexão, da autenticação e das regras do projeto configurado.

}

O projeto gerencia a programação. Não realiza venda de ingressos ou reserva de assentos.
